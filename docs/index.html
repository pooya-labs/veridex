                Automated CI/CD Pull Request Regression Gate
                
Prevent prompt or model degradation from merging into production with automated diff gates.

              

              

                veridex compare base.json curr.json --github-summary
              

            

          

          

            

              
GitHub Actions Workflow (.github/workflows/eval-ci.yml):

              

                
name: LLM Regression Gate
on: [pull_request]
jobs:
  eval:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - run: pip install veridex
      - name: Run Candidate Evaluation
        run: veridex run suites/prod.yaml -o current.json
      - name: Gate on Regression
        run: |
          veridex compare baseline.json current.json \
            --github-summary \
            --output-md pr_diff.md \
            --fail-on-regression

Engineered for Applied AI Reliability

      
Bridging systems engineering discipline with non-deterministic LLM behavior.


      

        

          
🧩

          
Custom Evaluator Plugins (@register_evaluator)

          
Register custom Python functions or evaluator classes with one decorator. Plug proprietary business logic, brand tone, or custom compliance rules directly into test suites.

        

        

          
🔭

          
OpenTelemetry GenAI & LangChain Native

          
Full support for OpenTelemetry GenAI semantic conventions (VeridexTracer) and LangChain callback interception (VeridexCallbackHandler) with zero friction.

        

        

          
🤖

          
Automated CI/CD Regression Gating

          
Run veridex compare --github-summary --fail-on-regression in GitHub Actions to block breaking prompt or model changes before merging.

        

        

          
🛡️

          
Deterministic & Schema Verification

          
Zero tolerance for schema violation. Validates nested objects, required fields, and types without requiring bloated external runtime dependencies.

        

        

          
🔍

          
RAG Faithfulness & Relevance

          
Measures factual groundedness against retrieved context, detects hallucinated statistics, and penalizes ungrounded numbers or dates.

        

        

          
📊

          
Model Matrix Benchmarking

          
Cross-benchmark multiple LLMs concurrently (`veridex matrix`) and produce an automated Leaderboard ranking pass rates, latency, and token cost.

        

        

          
⚡

          
Adversarial Fuzzing

          
Automatically mutate prompts with typo injection, casing flips, and noise to stress-test prompt brittleness before real users find bugs.

        

        

          
🌐

          
Veridex Studio (Web UI)

          
Launch a lightweight, zero-dependency local web studio with `veridex serve` to run tests and inspect failure traces interactively.

        

        

          
🔒

          
Luhn-Verified PII & Secret Shield

          
Built-in guards detect leaked API tokens, private keys, social security numbers, and credit cards with authentic checksum validation.
